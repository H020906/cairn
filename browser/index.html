Cairn — a volunteer in a browser tab

This page runs a Cairn work unit on the WebAssembly engine your browser already has. There is no Cairn engine here and there is not supposed to be: a volunteer executes the canonical module at full speed and returns an answer. It cannot say how it got there — no browser exposes the operand stack — so it does not try. That is ADR-0005, and it is the whole reason this file is 200 lines of glue rather than a port.

A running WebAssembly call cannot be interrupted from JavaScript. There is no timeout and no cancellation — once cairn_run is entered, that thread belongs to the workload. Terminate kills the worker outright, which is the only lever there is, and it is why enforcement on the honest path is allowed to be imprecise: a volunteer who stops early has produced no answer, not a wrong one. The exact, deterministic instruction ceiling lives on the dispute path, where a trap is a result two parties must agree on. See ADR-0009.
